# **App Name**: ImmersiveView

## Core Features:

- Background Display: Display the panoramic image as the background.
- 3D Parallax Effect: Implement a 3D parallax effect using `translate3d()` based on mouse movement.
- Subtle Zoom: Apply a subtle zoom effect by scaling the background image to 1.05.
- Central Focal Clarity: Ensure a focal point at the center of the image for clarity.
- Smooth Animation: Introduce smooth transitions to the 3D animation for a fluid user experience.

## Style Guidelines:

- Primary color: Deep, muted blue (#2B394B), complementing the night scene.
- Background color: Very dark blue-gray (#1A202C), creating depth and focus on the image.
- Accent color: Soft gold (#C0B3A3), mimicking city lights.
- Font: 'Inter', a sans-serif font with a neutral, modern style, for a UI overlay (not for use on the image).
- Smooth 3D parallax effect achieved using `translate3d()` for depth.
- Slight zoom animation on mouse movement to enhance immersion.
- Center focus with blurred edges to emulate depth of field.
